# 🎮 Jogo da Forca em Python

Um jogo da forca desenvolvido em Python, no qual o jogador precisa descobrir a palavra secreta antes de esgotar o número de tentativas disponíveis.

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos da linguagem Python, incluindo estruturas condicionais, laços de repetição, manipulação de strings e entrada de dados do usuário.
O jogo funciona no terminal e permite que o jogador tente adivinhar uma palavra letra por letra.

## 🚀 Funcionalidades

- 🎯 Sorteio de uma palavra secreta.
- 🔤 Tentativas de adivinhar a palavra por letras.
- ❤️ Número limitado de erros.
- 📊 Exibição das letras descobertas.
- 🏆 Mensagem de vitória ou derrota.
- 🔄 Atualização do progresso durante a partida.
